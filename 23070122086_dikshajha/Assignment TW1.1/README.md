# TW1.1 - Git Workflow & Collaboration

## Objective
Perform Git version control operations on a simple Python Flask application.

## Tasks Performed

### Task 1.1
- Initialized a new Git repository.
- Added the Flask application files.
- Created the initial commit on the main branch.

### Task 1.2
- Created a new branch: `feature/user-auth`.
- Modified the application by adding a print statement.
- Committed the changes.
- Pushed the branch to GitHub.

### Task 1.3
- Modified the same line on the main branch.
- Created a merge conflict.
- Resolved the conflict manually.
- Committed the resolved changes.
- Pushed the updated branch.
