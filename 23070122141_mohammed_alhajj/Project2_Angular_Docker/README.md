# Project 2 - Angular Application Dockerized

**Name:** Mohammed Al-Hajj

**PRN:** 23070122141

## Objective
This project demonstrates how to build and run an Angular application inside a Docker container. The main goal is to show how frontend applications can be containerized for portability, consistency, and easier deployment.

## Project Structure
- angular-docker-app/ - Angular application source files and configuration
- Dockerfile - Docker configuration for containerizing the app
- Screenshots/ - Images showing the development and containerization steps
