# Project 3 - Jenkins Pipeline Automation

**Name:** Mohammed Al-Hajj

**PRN:** 23070122141

## Objective
This project demonstrates how to create and run a Jenkins pipeline for automating the build and deployment process of a web application. The main focus is to show how Jenkins can be used to manage a CI/CD workflow efficiently.

## Project Structure
- agent1/ - First build agent or working environment
- agent2/ - Second build agent or working environment
- Jenkinsfile - Pipeline definition for Jenkins
- portfolio/ - Application files used by the pipeline
- screenshots/ - Screenshots captured during the setup and execution process
