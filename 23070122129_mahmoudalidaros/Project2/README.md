# Project 2 - Deploy Angular Application in Docker Container

## Objective
Deploy an Angular application using Docker and Docker Compose for both development and production environments.

## Technologies Used
- Angular
- Docker
- Docker Compose
- Node.js

## Description
This project demonstrates how to containerize an Angular application and deploy it using Docker. Docker Compose is used to simplify application deployment and environment management.

## Outcome
- Built Angular application
- Created Docker image
- Deployed using Docker Compose
