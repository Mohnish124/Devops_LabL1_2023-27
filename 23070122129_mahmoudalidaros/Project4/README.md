# Project 4 - Architecting Jenkins Pipeline for Scale

## Objective
Use Jenkins to configure a distributed pipeline that compiles and tests a Maven project using multiple Jenkins slave nodes.

## Technologies Used
- Jenkins
- Maven
- Java
- Docker

## Description
This project demonstrates a scalable Jenkins pipeline where build and testing tasks are distributed across different Jenkins agents to improve performance and efficiency.

## Outcome
- Configured Jenkins Master and Agents
- Built Maven project
- Executed distributed pipeline
