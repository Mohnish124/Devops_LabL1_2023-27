# Project 5 - Containerizing Spring Boot Application

## Objective
Deploy a Spring Boot application in Docker and demonstrate containerization for a retail company's web application.

## Technologies Used
- Spring Boot
- Docker
- Maven
- Java

## Description
This project demonstrates how to containerize a Spring Boot application using Docker. The application is packaged into a Docker image and deployed to simulate a retail company's web application environment.

## Outcome
- Built Spring Boot application
- Created Docker image
- Deployed application in Docker
