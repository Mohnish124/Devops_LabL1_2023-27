# Project 3 - Branching Development Model

## Aim
To demonstrate Git branching and merging workflow.

## Tools Used
- Git
- GitHub
- VS Code

## Workflow

1. Created a demo.txt file.
2. Committed the initial file.
3. Created a feature branch named feature-update.
4. Modified demo.txt on the feature branch.
5. Committed the changes.
6. Switched back to Devops_LabL1_2023-27.
7. Merged the feature branch.

## Git Commands Used

git checkout -b feature-update

git add .

git commit -m "Update demo on feature branch"

git checkout Devops_LabL1_2023-27

git merge feature-update

## Result

Successfully demonstrated Git branching, feature development,
commit and merge workflow.
