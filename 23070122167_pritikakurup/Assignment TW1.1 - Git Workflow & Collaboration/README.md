# Assignment TW1.1 - Git Workflow & Collaboration

## Objective

To learn the fundamentals of Git and GitHub by creating a repository, managing branches, committing changes, pushing code to GitHub, and resolving merge conflicts.

## Tools Used

- Git
- GitHub
- Python
- Flask
- Terminal (macOS)

## Tasks Performed

### Task 1.1 – Initialize Git Repository

- Created a new Flask application.
- Initialized a Git repository.
- Created the main branch.
- Added project files.
- Committed the initial application.
- Connected the local repository to GitHub.
- Pushed the project to the remote repository.

### Task 1.2 – Feature Branch Development

- Created a new feature branch named `feature/user-auth`.
- Modified the Flask application.
- Committed the feature implementation.
- Pushed the feature branch to GitHub.

### Task 1.3 – Merge Conflict Resolution

- Switched back to the main branch.
- Updated the application.
- Merged the feature branch into the main branch.
- Resolved merge conflicts.
- Committed the resolved changes.
- Pushed the updated main branch.
