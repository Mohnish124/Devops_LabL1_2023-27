# Maven Commands Used

## Clean Project

```bash
mvn clean
```

## Compile Project

```bash
mvn compile
```

## Run Tests

```bash
mvn test
```

## Package Project

```bash
mvn package
```

## Clean and Package

```bash
mvn clean package
```

## Learning Outcome

- Cleaned the Maven project.
- Compiled the portfolio application.
- Executed test cases.
- Packaged the project successfully.
