# Project 1 - Dockerizing Jenkins Pipeline

## Objective

The objective of this project is to automate the build process of a Flask application using Docker and Jenkins Declarative Pipeline.

---

## Technologies Used

- Docker
- Jenkins
- GitHub
- Python
- Flask

---

## Project Workflow

- Created a Docker image for the Flask application.
- Ran the Flask application inside a Docker container.
- Installed Jenkins using Docker.
- Connected Jenkins with GitHub.
- Configured a Declarative Pipeline.
- Successfully executed the pipeline.
