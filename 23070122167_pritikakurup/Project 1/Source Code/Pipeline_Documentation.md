# Jenkins Declarative Pipeline

## Build Process

```
GitHub Repository
        ↓
Jenkins Pulls Repository
        ↓
Workspace Created
        ↓
Execute Shell Commands
        ↓
Build Success
```

## Complete DevOps Flow

```
Flask Application
        ↓
Git Repository
        ↓
GitHub
        ↓
Jira Project
        ↓
Docker Container
        ↓
Jenkins Freestyle Build
        ↓
Declarative Pipeline
        ↓
Successful Build
```
