# Task 4 – Create Dockerfile

A Dockerfile was created to containerize the Angular application.

The Dockerfile uses a Node.js image, installs the project dependencies, copies the application files, exposes port `4200`, and starts the Angular development server.

### Dockerfile

```dockerfile
FROM node:22

WORKDIR /app

COPY package\*.json ./

RUN npm install

COPY . .

EXPOSE 4200

CMD \["npm", "start", "--", "--host", "0.0.0.0"]
```
